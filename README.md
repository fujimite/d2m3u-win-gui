# d2m3u-win-gui

A simple GUI for d2m3u on Windows.

### Development
- Clone with `--recurse-submodules`; `build_cli.bat` will build provided that `msys2` and required packages are installed.
- or place a built `d2m3u.exe` and all dlls in their relevant platform folder. e.g. `x64\Debug`
- Open project in Visual Studio
